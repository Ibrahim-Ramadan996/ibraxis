# ADR: Hybrid file persistence
Accepted for this development release by owner request. Preserve the existing Node runtime and in-memory relational queries, replace persistent SQL with a versioned native-file snapshot. Use stable project identifiers rather than moving directories on taxonomy changes. Separate public visibility from storage access; all remote storage is private. GitHub is not a transaction server: use one writer, local durable acknowledgments, conflict detection, and a non-force Git commit mirror. Auth credentials local-only. Tradeoffs: full checkpoint rewriting and memory use limit growth, Git history retains data, remote connectivity/quotas can interrupt sync. No paid service activated.
