# Search visibility ADR
Decision: render public content on server for every visitor, preserve existing URLs with explicit `?lang=ar|en`, derive canonicals from trusted environment, no indexing by default on staging. Separate home SEO strings from visible copy; use actual owner data only. Public HTML is not shared-cacheable because publication can be revoked immediately. Use a lightweight text similarity ranking for related projects, not fabricated AI similarity. Keep SQLite and existing single server.
References: https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics ; https://developers.google.com/search/docs/specialty/international/localized-versions ; https://developers.google.com/search/docs/fundamentals/seo-starter-guide ; https://developers.google.com/search/docs/appearance/structured-data/sd-policies ; https://developers.google.com/search/docs/appearance/site-names .
Risks: translated text must be complete for effective language targeting; full gallery/home payload grows with number of records; future pagination and thumbnail optimization required at scale. No live performance/indexing validation.
